# DevOps Labs

Hands-on labs for building, packaging and containerizing a small Java calculator application.

| Lab | Topic | Folder |
|-----|-------|--------|
| 1 | Build and package a Java app with **Maven** | [lab1-maven](./lab1-maven) |
| 2 | Build and package a Java app with **Gradle** | [lab2-gradle](./lab2-gradle) |
| 3 | Create **Docker** images for the Java app (build inside Docker vs. build locally) | [lab3-docker](./lab3-docker) |

Each folder has its own README with the steps, commands and results.

## Source code used

- Maven app: https://github.com/Ibrahim-Adel15/CalculatorMavenApp
- Gradle app: https://github.com/Ibrahim-Adel15/CalculatorGradleApp

The application source is not copied into this repository; each lab explains how to clone it.
